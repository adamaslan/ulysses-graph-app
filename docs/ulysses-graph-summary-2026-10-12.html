The Ulysses Graph

An interactive force-directed map of James Joyce’s Ulysses. Every episode, character, theme, motif and place is a node. Every quoted passage, technique and correspondence is attached to the ones it touches, and the full text is one click away.

HOW I COUNTED
I read “intersections” as links between nodes (each unordered pair of nodes counts once). Counts come from running the app’s own graphData.js, so they match what the graph draws. The README says 228 because it counts the core layer only; the Passages layer adds 96 more nodes and 840 more links.

The style

Paper and ink. The graph shares its look with the Quote Atlas it was built from: a warm paper ground, near-black ink, and four muted hues for the book’s four kinds of thing. There is no glow, no neon and nothing animating at rest. It replaced an earlier cyberpunk look (kept in docs/archive) because 228 nodes needed calm.

Colour says family, shape says type

Ten node types share five hues. Circles, diamonds and squares, solid or hollow, tell types apart inside a family, so colour is never the only signal.

Three-tier selection

The focused node is solid with a heavy ink outline. Its neighbours are tinted. Everything else drops to 15% opacity. Two functions control the whole effect.

Type that matches the book

Cormorant Garamond for titles, Source Serif 4 for Joyce’s text and summaries, IBM Plex Mono for IDs, page numbers and counts.

Light, dark and system

Every colour is a token defined once. The theme button cycles system, light and dark, and remembers the choice.

What makes it great

Every link is traceable to the text

Nodes are not invented. The 170 added nodes and their links are generated from the notes, and each passage keeps its block ID and source line range (e15q07, L847–863). Click a motif and you can read the exact lines that earned the link.

It shows the book’s hidden structure

Motifs like hands, eyes, music and the colour black cut across episodes that look unrelated. 841 co-occurrence links make those threads visible, and the slider hides the ones shared by only a few passages.

Five layers keep 324 nodes readable

Core, Motifs, Structure, All and Passages each show only the types they need. The default is never the full hairball.

Honest about its gaps

18 nodes have thin evidence and are drawn with a dashed outline. Flagged misfiled passages, such as a Sirens scene earlier filed under Cyclops, are corrected and marked.

You can rearrange it and keep it that way

A Spread slider, drag-to-pin (touch included), Timeline, Radial and cluster presets, and export/import of layouts. Pins survive filter changes and reloads.

Works on a phone, and without a mouse

Nodes are focusable buttons, a list view mirrors the graph for reading, reduced-motion is honoured, and the full corpus loads lazily so the first paint stays light.
